## Conversion scope and limitations

This edition was curated from the PDF text layer rather than treated as a blind extraction. Chapter and appendix boundaries follow the source; headings, navigation, code fences, formulas, tables, references, and malformed table-of-contents/list pages were repaired where the source made the intended structure clear. Repeated printed page numbers and running copyright/footer noise were removed.

No content has been translated. Hebrew and English wording are retained, but mixed right-to-left/left-to-right text may still display differently across Markdown renderers. Diagrams are represented by captions and collapsible text extracted from the PDF; their original geometry, color, typography, and some bidirectional ordering cannot be reproduced faithfully in plain Markdown. Use the PDF for visual interpretation, exact typography, or to resolve any ambiguity.
