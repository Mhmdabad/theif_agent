# Reference-v3 compatibility backend

`copthief_league_protocol/` is vendored from
<https://github.com/Imreec/copthief-league-protocol> at commit
`ad6557626587e09146af4283a5e808e7001343c5` under its included MIT license.

The application adapter is `thief_agent.reference_v3`; upstream files are kept unchanged so their
vectors and protocol state machine remain directly comparable with other teams using the kit.
